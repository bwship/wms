# Bob Wall Consulting — Landing Page

React landing page for Bob Wall consulting: Silicon Valley CTO, mobile/web/AI product development at a fraction of big-firm cost.

## Stack

- **React 19** + **TypeScript** (Vite)
- **Tailwind CSS** + **shadcn/ui**
- White + blue theme

## Commands

```bash
npm install
npm run dev    # http://localhost:5173
npm run build
npm run preview
```

## Deploy

Build output is in `dist/`. Deploy to Vercel, Netlify, or any static host. No backend required; contact form is client-only (wire to your preferred endpoint or service later).
